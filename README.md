# Jeopardy (custom board)

Serve this folder locally, open the page, and on **Before We Begin** pick a game slot, set teams, then **Start Game**.

```bash
python3 -m http.server 8765
# → http://127.0.0.1:8765/index.html
```

Hard refresh if the start screen looks stale: **Cmd+Shift+R**. Prefer the server URL over `file://`.

## Multiple game slots (one config file)

**Edit `config/game-config.js`.** Every board is a slot in `window.GAME_PROFILES`:

| Field | Purpose |
|-------|---------|
| `id` | Unique id (`hack-retreat`, `demo`, …) — used by sync/import |
| `title` | Name on the start-screen picker |
| `description` | Short blurb under the picker title |
| `gameTitle` | Big in-game heading (usually `JEOPARDY!`) |
| `teams` | Default team names (editable on the start screen) |
| `categories` / `finalJeopardy` / `themeMusic` / … | The board itself |

Shipped slots:

- **hack-retreat** — full Hack Retreat board (original party content)
- **demo** — short 3-category sample so multi-slot is obvious

### Add another game

1. Open **`config/game-config.js`**.
2. **Copy** an existing slot object in the `GAME_PROFILES` array.
3. Change **`id`**, **`title`**, **`description`**, then edit clues / teams / Final Jeopardy.
4. Reload the browser — the new card appears under **Choose a game**.
5. Optional host sheets: `node scripts/sync-answers.js <id>`

Set `window.GAME_DEFAULT_PROFILE = "hack-retreat"` (or another id) to choose which slot is selected first.

## Spreadsheet import

1. Copy `config/categories.example.csv` → `config/categories.csv` and fill rows (`category`, `value`, `clue`, `answer`, optional `audio` / `song` / `artist` / `category_note`).
2. Import into a slot:

   ```bash
   node scripts/import-from-csv.js
   node scripts/import-from-csv.js config/categories.csv demo
   ```

3. Reload the game. Optional: `node scripts/sync-answers.js <id>` for host printouts.

## Host answer sheets

```bash
node scripts/sync-answers.js           # default slot
node scripts/sync-answers.js demo      # one slot
node scripts/sync-answers.js --all     # every slot
```

Writes `data/jeopardy-answers.txt` / `.json` (and `data/jeopardy-answers-<id>.*` for non-default slots). Also refreshes `config/game-config.json`.

## Where files live

| What | Where |
|------|--------|
| Entry page | **`index.html`** |
| All game slots | **`config/game-config.js`** (edit this) |
| JSON mirror | `config/game-config.json` (regenerated by sync) |
| CSV template | `config/categories.example.csv` |
| Host tooling | `scripts/` (`sync-answers.js`, `import-from-csv.js`, `config-io.js`) |
| Host printouts | `data/jeopardy-answers*.json` / `.txt` |
| Theme loop | `assets/audio/jeopardy-theme.mp3` (path set per slot) |
| Audio clips | `assets/snippets/` |

**Start flow:** choose a game card → set team count & names → **Start Game**. **Reset Game** returns to setup with the last slot still selected.
